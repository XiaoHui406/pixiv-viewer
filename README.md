# PixivViewer

一个基于 uniapp 和 Vue3 开发的 Android 应用，将 Pixiv 网站封装为原生 APP。

## 功能特性

- 🌐 使用 WebView 加载 Pixiv 网站，提供原生应用体验
- 🔍 支持通过作品 ID 或画师 ID 快速查找内容
- 📱 适配 Android 状态栏，确保界面不被遮挡
- ⬅️ 支持 WebView 页面回退功能，不会意外退出应用
- 🎨 简洁的顶部工具栏设计
- 🛡️ **广告拦截功能** - 自动屏蔽Pixiv网站广告
- 💾 **图片下载功能** - 长按图片保存到相册
- 📋 **ID复制功能** - 一键复制作品ID或画师ID
- 🔎 **以图搜图功能** - 支持跳转到 ascii2d.net 进行以图搜图
- 📜 **浏览记录功能** - 自动保存浏览过的作品记录，支持本地缓存缩略图

## 技术栈

- **框架**: uniapp
- **前端**: Vue 3 (Composition API)
- **语言**: TypeScript / JavaScript
- **平台**: Android

## 主要功能

### 1. WebView 浏览
- 全屏显示 Pixiv 网站内容
- 自动适配状态栏高度
- 支持页面滚动和交互

### 2. 快速查找
- 通过作品 ID 跳转到指定作品页面
- 通过画师 ID 跳转到指定画师主页
- 使用原生菜单和输入框，确保在 APP 端正常显示

### 3. 导航控制
- 支持 Android 返回键回退到上一页
- 当无法回退时自动退出应用

### 4. 广告拦截（1.1版本新增）
- 自动屏蔽Pixiv网站广告
- CSS注入隐藏广告元素
- MutationObserver动态清理新加载的广告
- 资源请求拦截器阻止广告加载
- **v1.4.1优化**: 修复了广告屏蔽脚本会屏蔽登录时人机验证的问题

### 5. 图片下载（1.2版本新增）
- 长按图片弹出下载菜单
- 支持保存图片到手机相册
- 防重复触发机制，避免频繁弹出菜单
- 支持多种图片格式下载
- **v1.4.1优化**: 修复了下载原图时无法正常工作的问题

### 6. ID复制功能（1.3版本新增）
- 在作品页面或画师页面点击右上角菜单
- 一键复制作品ID或画师ID
- 支持新版和旧版URL格式识别
- 智能提取URL中的ID信息

### 7. 以图搜图功能（1.4版本新增）
- 在右上角菜单中添加"以图搜图"选项
- 点击可跳转到 ascii2d.net 网站
- 支持通过图片搜索相似作品
- **注意**: 首次使用会触发 Cloudflare 人机验证，验证后退回重新搜索即可

### 8. 浏览记录功能（1.5版本新增）
- 自动记录浏览过的作品
- 本地缓存作品缩略图，无需重复下载
- 2列网格展示，支持点击查看详情
- 支持清空和长按删除单条记录

## 开发说明

### 环境要求

- HBuilderX 或 uniapp 开发环境
- Node.js

### 运行项目

1. 使用 HBuilderX 打开项目
2. 选择运行到 Android 设备或模拟器
3. 或使用 uniapp CLI 进行开发

### 打包发布

1. 在 HBuilderX 中选择"发行" → "原生 App-云打包"
2. 配置 Android 打包参数
3. 等待打包完成并下载 APK

## 注意事项

- 本项目仅用于学习和研究目的
- 请遵守 Pixiv 的使用条款和版权规定
- 建议在合法合规的前提下使用

## 登录说明

- **推荐方式**: 直接使用 Pixiv ID 和密码登录
- **原因**: Google、Twitter 等第三方登录在 WebView 环境中可能遇到兼容性问题
- **安全性**: 直接登录方式更安全，避免了第三方登录的安全策略限制
